Through this site we can help you install four plug-ins–Shockwave, Flash, QuickTime, Acrobat Reader and JavaScript. They all work with newer versions of the Netscape and Internet Explorer browsers.

If you use a version of the AOL browser older than 4.0, you may have trouble using the QuickTime plug-in. To avoid this problem, we suggest that you switch to the most current version of the AOL Internet package or download the Netscape or Internet Explorer browser. An important note concerning security:
The Shockwave games at AmericanGirl.com will not load if you have set your Web browser or anti-virus software security settings to maximum or high. These settings also prevent downloading the free plug-ins discussed in this Tools section. If you have trouble downloading and are using security software or Internet Explorer 5.0 browser, AOL 5.0 browser and above, or Netscape 6.0 browser, this setting may be the problem. The security setting is easy to change, but please ask your parents before making any changes.

  • For computers with Windows operating systems, the security settings are in the browser's Internet Options file.

  • For computers with Macintosh operating systems, you can change the security setting in the browser's Preferences file.
