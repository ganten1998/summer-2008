A Preservation Project

About the Archive

This application is a faithful offline snapshot of americangirl.com as it appeared on 11 July 2008 — the era of the Kit Kittredge film, Nicki Fleming as Girl of the Year, and the original lineup of historical characters Felicity, Addy, Kit, Molly, Samantha, Kaya, Josefina, and Kirsten.

Every HTML page, stylesheet, and image is pulled from the Internet Archive's Wayback Machine. Every Flash .swf game plays directly inside the launcher window using Ruffle, an open-source Flash emulator (Rust → WebAssembly) — so games load and auto-play exactly as they did in a 2008 browser, without any plugin. A bundled Adobe Flash Player.app projector is included as a fallback for the handful of titles Ruffle hasn't perfected yet.

Note: a handful of titles (Addy's Mancala, several Kit railway scenes, a few crafts) were authored in Adobe's Shockwave format (.dcr), which is a different runtime that Adobe end-of-lifed in 2019. There is no usable standalone Shockwave projector for modern macOS, so those titles are preserved in the bundle but hidden from the gallery; they can be played in any environment that still has Shockwave Player installed.

Where the original snapshots are corrupted or missing, the launcher attempts to pull a repaired copy of the game from the Flashpoint Archive preservation community. Pages that weren't captured in the original mirror are transparently fetched on demand from the Wayback Machine and cached locally so they load instantly next time.

How to use

  • Enter the Website — opens the homepage exactly as a visitor would have seen it that summer; Flash hero animations and embedded games auto-play inline.
  • Game Gallery — a curated index of every playable Flash game we recovered, grouped by character and section. Click any tile to play in the inline viewer.
  • Fallback projector — if a game shows a crimson "Open in Flash Player" tile, click it to launch the bundled Adobe projector — useful for the few SWFs Ruffle can't render yet.
